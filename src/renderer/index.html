使用说明

      
    
        
  1. 目标网址：要抓取的完整 URL（含 https://）。
    2. 
        
  2. 保存目录：抓取结果（源码 / HAR / 快照）保存的位置。
    3. 
        
  3. 抓取内容：
          
      
            
    • 源码资源：JS、CSS、字体等静态文件，按原目录结构保存。
      • 
            
    • 网络数据包（HAR）：完整请求/响应记录，可直接拖入 Chrome DevTools 的 Network 面板或 Charles / Fiddler 分析。
      • 
            
    • 页面快照：JS 执行后的完整 DOM（非原始 HTML）。
      • 
            
    • 媒体文件：图片 / 视频 / 音频（体积可能较大）。
      • 
          
    
        
    4. 
        
  4. 无头模式：勾选则不显示浏览器窗口；遇到需人工登录 / 过验证码的站点可取消勾选。
    5. 
        
  5. 滚动次数：对懒加载页面（如瀑布流）设置正向滚动次数以触发更多资源加载。
    6. 
      

      
输出结构

      
保存目录/
├── source/<host>/…      JS / CSS / 字体
├── media/<host>/…       图片 / 视频 / 音频
├── other/<host>/…       JSON / XML 等
├── page.html            渲染后 DOM
├── page-info.json       标题等元信息
├── network.har          网络数据包
└── metadata.json        抓取清单

      
提示：本工具仅用于合法授权的安全测试、逆向学习与自有站点备份。请遵守目标站点服务条款与当地法律。
